# Dashboard screenshots

Place the final portfolio screenshots in this directory with these exact names:

- `overview.png` — index trends, market direction, movers, and sector heatmap.
- `signals.png` — scanner controls and ranked crossover results.
- `stock-view.png` — price/volume chart, technicals, delivery volume, and fundamentals.

Capture them from an authenticated local session at `http://127.0.0.1:5173/`.

Before saving each image:

- Hide API keys, API secrets, request tokens, and access tokens.
- Avoid showing personally sensitive account information.
- Use representative live or last-session data.
- Keep a consistent browser width and dark theme.
- Verify that dates, percentages, and heatmap colors contain real values.
